# Strategy optimisation

Predefine parameter ranges, objective, search budget, split boundaries and seeds. Search training and validation data only. Preserve every configuration and result, including failures. Never select parameters from final holdout performance.

Inspect sensitivity surfaces and neighbouring settings, then test costs, slippage and regimes. Prefer stable parameter regions and simple rules over a single peak. Report search size and selection-bias risk.
